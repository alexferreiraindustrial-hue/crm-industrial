# Vocabulário de logística — Bruna Logística

O Captain (estagiário) deve **aprender e usar** estes termos ao ler conversas, montar resumos e criar tarefas.  
Objetivo: entender o domínio da Bruna (frete, prazos e operação) sem inventar dados.

## Frete e custo

| Termo | Significado / uso |
|-------|-------------------|
| **Frete** | Preço/condição do transporte da carga |
| **Cotação de frete** | Pedido ou oferta de valor para um trajeto |
| **Frete peso / frete valor** | Modalidades de cálculo (por peso ou por valor da nota) |
| **Ad valorem** | Taxa sobre o valor da mercadoria |
| **GRIS / seguro** | Taxas/seguro ligados ao risco da carga |
| **Pedágio** | Custo de pedágio repassado ou embutido |
| **Descarga / TAS** | Taxas de descarga ou serviços no destino |
| **Tabela de frete** | Lista de preços por rota/peso |

## Prazos e tempo

| Termo | Significado / uso |
|-------|-------------------|
| **Prazo** | Data ou janela combinada (coleta, entrega, resposta) |
| **Prazo de entrega** | Quando a carga deve chegar ao destino |
| **Prazo de coleta** | Quando a carga deve ser retirada na origem |
| **SLA** | Acordo de tempo de atendimento ou entrega |
| **Lead time** | Tempo total origem → destino |
| **Atraso** | Estouro de prazo; marcar prioridade e pendência |
| **Previsão / ETA** | Estimativa de chegada |
| **Janela de entrega** | Intervalo em que o cliente recebe |

## Operação e documentos

| Termo | Significado / uso |
|-------|-------------------|
| **Coleta** | Retirada da mercadoria no remetente |
| **Embarque** | Saída da carga |
| **Entrega / ocorrências** | Chegada e eventos no trajeto |
| **CTE / CTe** | Conhecimento de Transporte Eletrônico |
| **NF / NFe** | Nota fiscal da mercadoria |
| **Romaneio** | Lista de volumes/pedidos no carregamento |
| **Canhoto** | Comprovante de entrega assinado |
| **Ocorrência** | Evento (recusa, avaria, extravio, reentrega) |
| **Redespacho** | Troca de transportador no meio do fluxo |
| **Armazém / CD** | Ponto de guarda ou cross-dock |

## Pessoas e papéis (no chat)

| Termo | Significado / uso |
|-------|-------------------|
| **Embarcador / remetente** | Quem envia a carga |
| **Destinatário** | Quem recebe |
| **Transportadora** | Quem executa o frete |
| **Motorista** | Condutor; às vezes citado em status de rota |

## Como o estagiário deve aplicar

1. Ao resumir, **nomeie** frete, prazo, coleta, entrega, CTE/NF quando aparecerem.
2. Toda menção a data/hora vira candidato a **tarefa com prazo**.
3. Toda menção a valor de frete ou cotação vira nota: valor, rota, validade da cotação (se dita).
4. Se o termo for ambíguo, registre na nota interna: *“cliente disse X; interpretar como Y?”* — não pergunte ao cliente.
